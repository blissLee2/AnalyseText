Text message Analyser

A simple java program application that analysis a text.  This project demonstrates fundamental Java programming concepts such as string manipulation, loops, conditional statements, sets, and functions.

The application analyzes a user-entered message and displays:

- 📝 Original text message
- 📏 Total message length
- 🔤 Number of vowels
- 🔡 Number of consonants
- 🌟 Unique letters
- 🔁 non-unique (repeated) letters
